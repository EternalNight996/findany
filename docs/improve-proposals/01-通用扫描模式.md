# 改善提案（一）：通用扫描模式

| 项目 | 内容 |
| --- | --- |
| 提案名称 | 用工具自动检索目录内容，替代人工逐个打开文件查关键字 |
| 改善类别 | 效率 + 安全（减少人工接触受控数据） |
| 提案人 | 【填写】 |
| 日期 | 【填写】 |

## 一、为什么提这个改善（现状与问题）

现在要确认「某批文件里有没有出现某个关键字（例如 `IT6563`）」「谁命中了、谁没命中」，常见做法是：

1. 人用资源管理器进目录，一个个文件夹点开；
2. 用记事本 / Excel 打开文件，Ctrl+F 找关键字；
3. 找到的记在本子或 Excel 里，再手工汇总。

**问题（痛点）**：

| 痛点 | 说明 |
| --- | --- |
| 慢 | 目录大、文件多时，人翻一遍要**几十分钟到几小时**【待实测】 |
| 会漏 | 人眼会疲劳、会跳文件，漏一个就可能变成后续客诉 |
| 会看错 | 文件编码不一样（UTF-8 / GBK / UTF-16），记事本打开是乱码，关键字就被判成「没命中」 |
| 没记录 | 查完没有留档，客户或后工序再问一次，只能重查一遍 |
| 风险 | 受控数据（含 SN、产品信息）被人工反复打开、另存、转发，外发渠道不可控 |

## 二、改善方案

用现成的桌面工具 **findany（通用扫描模式）** 替代人工翻查，流程只留三步：

```
放目录  →  填关键字、点「开始扫描」  →  出 Excel + 命中文件落盘
```

**能力对照（工具能做到什么）**：

| 能力 | 说明 | 对痛点的作用 |
| --- | --- | --- |
| 全目录递归 | 指定根目录下所有子目录、文件一次扫完 | 解决「慢」 |
| 包含 / 不包含 | 一次看清「谁命中 / 谁没命中」 | 解决「漏」 |
| 并发扫描 | 线程 1~64 可调，I/O 密集 | 解决「慢」 |
| 编码智能 | 自动探测 + utf-8 / GBK / UTF-16 严格降级 | 解决「乱码看错」 |
| 结果表边跑边出 | 每批结果即时上屏，不用等全部跑完 | 体感快、随时可停 |
| 一键导出 Excel | 明细 + 摘要双 sheet，含「记录未命中」 | 解决「没记录」 |
| 命中文件落盘 | 按 `out/日期时间/目录/文件` 复制留存，同名自动加序号 | 留证据、可追溯 |
| 二进制 / 超大文件跳过 | 不会卡死、不会误判 | 稳定性 |

**安全保障**：

- 全程在本机跑，**不上传、不外发**，数据不出本地；
- 命中文件只复制到本机 `out/` 批次目录，原始文件不动、不修改；
- 输出目录自动排除，不会自己扫自己。

**建议参数**（可现场调）：

| 场景 | 并发线程 | 单文件上限 | 说明 |
| --- | --- | --- | --- |
| 产线机台（别抢生产） | 4 | 20MB | 进程优先级设 `below_normal` |
| 办公 PC | 8~16 | 20MB | 默认 |
| 服务器 | 4 | 20MB | 配合每批休眠 20~200ms |

## 三、实施步骤

1. 选一个典型目录（建议先挑最难的那批），用现成工具跑一次，记录「人工耗时 vs 工具耗时」。
2. 确认关键字、匹配模式（包含 / 不包含）、文件扩展名、是否递归，填好后**保存配置**，下次一键复用。
3. 把「工具跑一遍 + 导出 Excel + 归档到批次目录」写进作业指导书（一页图文）。
4. 培训 1 次（约 15 分钟）：放目录 → 填关键字 → 开始 → 导出 → 打开输出目录。
5. 试运行 2 周，收集问题后固化参数，纳入日常点检。

## 四、改善效果

| 指标 | 改善前 | 改善后 | 说明 |
| --- | --- | --- | --- |
| 单批排查耗时 | 【待实测】分钟/小时 | 【待实测】分钟 | 工具实测参考：**29400 个文件、release 版扫描 3.5 秒** |
| 漏检 | 会发生 | 0（全量逐文件判定） | 判定口径固定，不依赖人眼 |
| 乱码误判 | 会发生 | 0（多编码降级链） | utf-8 / GBK / UTF-16 严格降级 |
| 留档 | 手写记录、易丢 | 每批 Excel 明细 + 摘要 + 命中文件落盘 | 客户再问可一次调出 |
| 人工接触受控数据 | 反复打开、另存 | 只在工具内查看 | **安全性改善点** |

## 五、风险与应对

| 风险 | 应对 |
| --- | --- |
| 关键字填错导致结果不对 | 先用小目录验证一遍（抽 3~5 个文件人工核对） |
| 目录过大、内存占用高 | 工具内置内存看门狗，到上限主动安全停止并写明原因；可设文件数上限 |
| 扫到不该扫的目录 | 固定「扫描目标」路径 + 输出目录自动排除，扫码前确认路径 |
| 网络盘 / 共享盘慢 | 调小线程、加每批休眠 |

## 六、验收标准（做完怎么算成功）

- [ ] 选定的典型目录，工具结果与人工抽查结果**一致**（抽 10 个文件核对）。
- [ ] 导出的 Excel 能直接给后工序 / 客户用（明细 + 摘要齐全）。
- [ ] 作业指导书完成，操作人能在 30 秒内独立跑完一轮。
- [ ] 连续试运行 2 周，无漏检、无因乱码造成的误判。
