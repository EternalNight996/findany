## 三份提案共同的改善主线

1. **少经人手**：数据由工具直接对接服务器，人只负责放目录、看结果 → 外发渠道少一个，客诉风险少一层。
2. **可追溯**：每一次扫描 / 上传都有批次目录、Excel 明细、审计 CSV、`R<...>R` 结论，出问题能倒查到单台。
3. **不误判**：该传没传、传了没成功，一律不判 PASS（`status=false`），不会「看起来完成了，其实漏了」。
